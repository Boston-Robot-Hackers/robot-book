# Introduction to Robotics

A robotics textbook comparing drafts generated by two AI assistants: Claude Sonnet 4.6 and GitHub Copilot (GPT-4.1).

## Structure

```
claude/     — chapters drafted by Claude Sonnet 4.6
copilot/    — chapters drafted by GitHub Copilot
```

Each set covers:
- Introduction
- Chapter 1: Defining Robots
- Chapter 2: Robot Hardware
- Chapter 3: Robot Software Architecture
- Chapter 4: Sensors Overview
- Chapter 5: Working with LIDAR
- Chapter 6: Computer Vision

## Website

Built with Jekyll, deployed to GitHub Pages automatically on push to `main`.

To enable: repo Settings → Pages → Source → **GitHub Actions**

## Local preview

```bash
gem install bundler
bundle install
bundle exec jekyll serve
```
